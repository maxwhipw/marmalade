Symbols Nerd Font Mono — MIT, plus the licenses of the icon sets it aggregates
==============================================================================

res/font/symbols_nerd_font_mono_regular.ttf

The terminal draws private-use-area icon glyphs (powerline separators,
git/branch marks, file-type and distro logos) with this font — it is what
makes real shell prompts (starship, powerlevel10k, opencode) render as
icons instead of tofu.

Bundled UNMODIFIED from the official Nerd Fonts release:

  https://github.com/ryanoasis/nerd-fonts/releases/tag/v3.4.0
  asset NerdFontsSymbolsOnly.zip, file SymbolsNerdFontMono-Regular.ttf
  sha256 f0f624d9b474bea1662cf7e862d44aebe1ae1f6c7f9cb7a0ca5d0e5ac9561c60

The shipped file's own name table (nameID 0) reads:

  Copyright (c) 2016, Ryan McIntyre

and the LICENSE inside that release archive is the MIT text reproduced
below. Nerd Fonts' root LICENSE states the same rule the aggregate rests
on: "Source files not in folders containing an explicit license are
using the MIT License (MIT)".

TRADEMARKS
----------

Many of these glyphs are brand marks (distro logos, product icons) and
remain trademarks of their owners. Both Font Awesome and Font Logos state
the same condition: use a brand icon only to refer to the company,
product or service it depicts, never to imply endorsement. Marmalade uses
them only as the terminal's rendering of whatever glyph the remote shell
emits.


A NOTE ON THE MIT / OFL OVERLAP
-------------------------------

Nerd Fonts distributes the merged font under MIT while some of its
constituent glyph sets are OFL-1.1, whose clause 5 asks that the Font
Software be distributed entirely under that license. Marmalade does not
have to resolve that tension: the file is redistributed UNMODIFIED, under
its original name, with every upstream copyright notice and license body
carried alongside it. That satisfies MIT's notice requirement, OFL clause
2 (notice and license travel with the font), and CC BY 4.0's attribution
requirement at once. The font is not sold on its own (OFL clause 1) and
no Reserved Font Name is reused (clause 3).
